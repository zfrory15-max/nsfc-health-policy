# 医疗卫生管理研究方法专项

先做[研究方法共性检查](review-checklist.md#module-f)。只对实际采用相应设计的子研究读取下列分支，用问题、资料与拟作出的判断来识别设计。题目只提及某方法作为研究背景时无需触发。一个复杂项目可对不同子研究采用不同分支；多处暴露同一缺陷时合并为一条原稿批注。

[M01 预测](#m01) · [M02 政策评价](#m02) · [M03 干预试验](#m03) · [M04 质性与实施](#m04) · [M05 混合方法](#m05) · [M06 症状网络](#m06) · [M07 量表](#m07) · [M08 数字系统](#m08)

每条结论注明对应的主清单编号，再记分支和具体环节，便于复查。例如“F07／M02 患者负担口径”。先说明缺口将影响哪项结论，再给最小修复路径。申请人可补证据或同步缩小主张。下面是研究方法判断，严谨性应按项目承诺及研究阶段解释。

<a id="m01"></a>
## M01 预测、预警与风险分层

触发条件是要用某时点可得的信息预测其后或当时未知的个体结局，或按风险安排后续管理。只研究变量之间的解释性关联时先厘清目标。

| 核查点 | 阅读与核对 | 完成标准 |
|---|---|---|
| 使用情境 | 谁为谁、在什么时点、预测哪个时间窗的什么结局？超过什么风险水平会怎样行动？ | 开发、评价与实际应用针对同一对象、预测时点和结局。纯模型开发可把实施效果留作后续研究。 |
| 数据泄漏 | 按预测时点回看输入是否已知。核对同一患者多次就诊、同院数据、插补与特征筛选是否跨越评价边界。 | 训练和验证划分、预处理与调参过程可复述，预测过程不会使用未来信息或评价数据的结局。 |
| 样本估算 | 对照事件数或结局分布、候选参数个数、随访丢失和验证样本的独立需求。 | 原始参数、分母、开发和验证的数字能复算，数据规模足以支持拟估计的性能，或有简化方案。 |
| 验证性质 | 写出开发与测试患者、中心、时间的关系。若从同一队列随机拆分，即使称作“独立测试集”，也不能证明跨中心适用性。 | 验证命名准确，与地域、时间或人群的外推范围匹配。若无法获得外部资料，明确本项目可支持的验证层级。 |
| 性能与用途 | 对照原有评分或简单模型，以及区分度、校准、误差和相应不确定性。做临床决策主张时核查阈值、漏判或误判后果。 | 评价指标能检验项目实际主张；阈值有依据；模型性能、可实施性和改善患者结局各有清楚的证据边界。 |

详见[BMJ 预测模型开发指南](https://www.bmj.com/content/386/bmj-2023-078276)。

<a id="m02"></a>
## M02 政策评价、准实验、医保与药品集采

触发条件是利用政策调整、实施差异或制度分组推断影响。研究目标限于描述采购趋势时，不强求因果识别设计。

| 核查点 | 阅读与核对 | 完成标准 |
|---|---|---|
| 实际暴露 | 用一个地区或机构的实际例子定位公告、执行、过渡、提前备货及观察期。核对政策约束对象是否实际参与。 | 能说明该地区何时真正受到干预、为什么，日期与暴露定义在图表和分析中一致。 |
| 可信比较 | 画出“单位×时期”的比较。分期实施时注明当期受影响、尚未实施、存在预期反应和已经全部覆盖的时段。中断时间序列则写清预期的反事实走势。 | 按所选设计说明每个效应的比较来源、可比性假设及覆盖范围；无可信对照的时段收窄解释。 |
| 识别风险 | 选取实际可能发生的同期支付改革、处方品种替代、样本进出、外溢或编码变化。查方案能否区分它们与政策作用。 | 对主要替代解释有针对性检查，例如比较政策前走势、改变实施窗口或分析受影响较小的品类。说明未能排除的解释。 |
| 结局层级 | 对价格、数量和负担分别查记录单位、计量规格、品种构成、分子分母和测量窗口。 | 例如，只有医院采购资料时可分析可比规格采购单价和数量；若声称患者自付或可负担性改善，须有相应患者层面的支付与负担定义。 |
| 推广与执行 | 比较纳入地区、机构、药品或患者与政策总体适用范围，关注执行强弱与异质性。 | 清楚说明有证据覆盖的对象、时期和实施条件，不能独立鉴别的政策成分保留不确定性。 |

<a id="m03"></a>
## M03 干预试验与效果评价

触发条件是给予患者、团队或机构一项干预，并拟评价其效果。可接受性或小规模预试按自身目标判断。

| 核查点 | 阅读与核对 | 完成标准 |
|---|---|---|
| 干预和常规照护 | 复述谁提供、谁接受、实施内容、剂量或频率、时长、针对何种需求，比较组平时接受什么。 | 能据此分清两组实际经历，或在单组设计中分清干预前后的照护环境。 |
| 分组与测量单位 | 检查如何分配、知情后选人是否有偏差、不同组间信息污染，以及同机构患者的相关性。在适宜处说明独立或盲法结局判断。 | 对实际可行的分配方式有交代，分析与实施层级一致；不能盲法等局限有相应控制或解释。 |
| 主要结局 | 将主要结局、评价者、随访窗口、缺失和失访与样本估算逐项核对。 | 主要比较可执行且可解读，终点变化和缺失的处理有依据。 |
| 到位程度 | 干预实际交付是否与方案一致，参与率、接受性、退出原因、剂量或人员差异如何观察。 | 尤其在未见效果时，能区分干预实施不足与实际作用有限。 |
| 声明边界 | 若采用单组前后比较，列出同期治疗进展或共同趋势等解释；若仅做可用性评估，追问衡量的实际属性。 | 补充合适参照或收窄因果断言；初步研究可形成对可行性、接受度、招募或下一轮设计的明确结论。 |

<a id="m04"></a>
## M04 质性、参与式与实施研究

触发条件是用访谈、观察、参与式设计、案例或过程资料，解释服务实践、需求、实施过程或机制。按方法目的评估，不用量化效果检验给探索性项目评分。

| 核查点 | 阅读与核对 | 完成标准 |
|---|---|---|
| 选案 | 把研究问题与参与者角色、机构差异和选案标准并列。判断失败或低执行案例、偏离预期者能否提供关键的补充视角。 | 说清为什么找这些人、哪种遗漏会伤害结论、发现何种信息缺口会补访。样本量有信息充分性的合理解释。 |
| 可观察过程 | 对核心问题点出访谈、记录或观察中可得到的具体材料。例如请参与者追述一次实际随访，查清考核要求、人员排班与行为的先后。 | 材料获取办法能辨别行为过程；仅取得受访者叙述时，将主张限定在被报告的过程或经验。 |
| 参与程度 | 找到患者、照护者或一线人员在哪一环节参与决策，例如选拍摄主题、确定干预内容、审议原型修改。 | 至少举出一项参与者意见可能改变的设计选择，说明不同意见如何被记录和处理。 |
| 分析可追溯 | 核查从原始记录到编码、主题、案例比较或过程解释的路径，考虑研究者角色和相互矛盾材料的处理。 | 读者能追到支持与挑战某一解释的资料。若宣称多源核对，交代各来源具体核对哪一事实。 |
| 机制与反例 | 若只访谈高执行机构负责人，却拟概括普遍机制，追问任务填报是否等于实际服务及是否有其他解释。 | 结合差异选案和过程证据检验机制，或将研究对象与结论限定到实际采集的范围。 |

<a id="m05"></a>
## M05 混合方法

触发条件是定量与定性证据要共同回答科学问题。分别使用两种工具并不能自动形成混合设计。

| 核查点 | 阅读与核对 | 完成标准 |
|---|---|---|
| 两部分的分工 | 写明每一部分能回答什么、单独使用时遗漏什么。 | 可以解释为什么同一项目值得取得两种资料。 |
| 顺序与抽样 | 标出探索先行、解释后续或并行实施；核对前一阶段何时产生可供后一阶段使用的对象、变量或问题。 | 次序、用时、前后样本的联系和接入规则可执行。 |
| 整合点 | 取一个具体发现追踪怎样改变访谈提纲、招募对象、模型变量、干预成分或最终解释。 | 明确谁在何时依据什么整合，能指出一个实际决定；仅在报告末尾各写一段时应补设计。 |
| 分歧解释 | 设计一个可能的分歧情境，例如费用下降但患者困扰加重，核查资料如何并列、补查或界定结论。 | 两类资料一致和不一致时都有可解释的处理办法，未能解释的差异如实保留。 |

<a id="m06"></a>
## M06 症状网络与纵向网络

触发条件是以节点、边、中心性、网络变化或个体网络支持判断。仅以流程图表示关系时不启动。

| 核查点 | 阅读与核对 | 完成标准 |
|---|---|---|
| 估计对象 | 区分群体间差异、同一人内部变化、不同时间的状态或群体之间比较。核查节点对应什么、边表示何种条件关系。 | 网络所用观测与推论层级一致，读者能解释一条边的统计含义。 |
| 信息量和时间结构 | 分别列患者数、每人或每个时间窗的可用测量波次、节点和待估关系，核查测量间隔与症状变化速度。 | 拟建网络与实际样本结构相称。个体网络或分窗估计说明每个单位可用的观测和信息不足时的简化办法。 |
| 构建可复述 | 核对量表编码、缺失、分布、节点选择、估计及正则化依据，区分布局和参数估计。 | 能说明数据如何得到边和指标。节点靠近或绘图位置不能单独作为统计联系或先后顺序的依据。 |
| 稳定性与变化 | 若要按中心性排序或解释网络差异，问边与指标的精度、排序稳定性、测量可比性以及重复观测依赖如何检查。 | 核心解释与精度相称。排序不稳定时能限制节点优先级的结论或另行验证。 |
| 干预外推 | 若提出干预某节点会改变其他症状，回查是观察相关、模拟扰动还是真实干预比较。 | 候选靶点、预测结果与实际干预效果清楚区分；主张实际效果时有后续可检验的设计。 |

<a id="m07"></a>
## M07 量表与患者报告结局

触发条件是开发、引进、改编量表，或把患者报告测量用于主要判断。仅使用已获充分支持的成熟工具时重点核对适用性、时间窗及解释。

| 核查点 | 阅读与核对 | 完成标准 |
|---|---|---|
| 构念与用途 | 说明测量体验、症状、负担或能力的哪一方面，为筛查、区分、随访还是评价变化所用。 | 构念、目标人群、使用场景和期望解释一致。患者体验与客观费用等互补构念分别测量。 |
| 现有工具 | 核对版本、语言、原人群、适用年龄或场景、内容覆盖、授权及施测负担。 | 能说明为什么复用、改编或开发，已翻译、目标人群效度和纵向解释能力的证据分开。 |
| 测量证据 | 根据用途核查内容可理解性、结构、可靠性、效度或对变化的反应，辨认有无适当的对照测量及样本。 | 关键测量主张有对应的检验。不以单一信度系数代替对主要用途的全部验证。 |
| 实际施测 | 查计分、缺项、重复测量、受访人或代答者、时点和基于得分的行动。 | 读者能判断不同人、语言版本或时点的得分何时可比，且施测负担在目标场景可接受。 |

<a id="m08"></a>
## M08 大模型、推荐系统与数字平台

触发条件是开发或评价智能问答、推荐、决策支持或数字化服务。区分已运行的原型、拟开发功能及效果主张。

| 核查点 | 阅读与核对 | 完成标准 |
|---|---|---|
| 完整使用链 | 以一次具体任务复述谁输入什么、系统据何生成什么、谁复核或覆写、最终谁采取何种行动。 | 输入到行动能走通。若标题强调学习或双向反馈，能指出哪些反馈更新了什么，更新何时被复核。 |
| 资料及评价独立性 | 核查知识库或训练资料来源、权限与更新时间，避免同一人、案例、问题答案或指南内容被不当用于开发与声称独立的测试。 | 可复述划分及质量控制，能区分对已有知识的检索能力与未见病例上的泛化主张。 |
| 参照与预设判据 | 说明相对人工常规流程、简单检索或已有模型的改进是什么，谁按何标准评判关键输出。 | 对准确、可追溯、耗时、负担等拟衡量的属性有指标，比较条件清楚。 |
| 失败与保护 | 查是否实际测试不完整信息、冲突指引、有害建议、答非所问或超出适用范围的情境。若涉及患者行动，核查升级人工的条件及责任。 | 至少能说出最可能伤害主要目标的一类失败及发现、复核、纠正办法。既有原型暴露的问题可用来支持新任务。 |
| 不同评价层级 | 把技术输出质量、用户能否完成任务、服务流程改变、患者或管理结局逐项找对应证据。 | 各层的结论限于实际观察。只有界面测评时可完成可用性目标，主张实际获益须另有相应比较与观察。 |
