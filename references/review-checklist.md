# 医疗卫生管理项目评阅清单

下列条目用于评阅。交付时，把每项在这份稿子里查到了什么填入结果表。整稿逐项呈现 A–H 的 66 项和 X 的 4 项，并附实际命中的[方法专项](method-checks.md)；只问标题就交 A 模块的表，只问一个章节就交该章节的表。

[A 标题](#module-a) · [B 背景和意义](#module-b) · [C 文献回顾](#module-c) · [D 研究内容](#module-d) · [E 关键问题](#module-e) · [F 研究方法](#module-f) · [G 研究基础](#module-g) · [H 其他部分](#module-h) · [X 全稿复核](#cross-checks)

**判定办法。** 逐条记“通过／需修改／待核实／不适用”，附原句、章节、表格单元或 PDF 物理页。表中第三栏既是初评判据，也是复查关闭条件。核对[当年 G04 学科边界](annual-rules.md#g04-fit)，把方向判断落在 A01、B02、E01 和 X01 等相应行。有稿内证据的实质缺口记“需修改”；材料缺失、原页不可读或代码未给，相关信息记“待核实”。只给标题时可点评已表达的管理问题，不能仅凭病种名称下范围结论。整稿有未关闭的问题也须做跨章节核对。

**从判据到批注。** 在读者最需要信息的地方挂批注。区分年度规则、方法学判断和团队写作经验。严重度取决于本项目的后果。比如同一处样本数有两种分母，能局部纠正且不会改变可行性时是局部问题；若导致可招募人数无法满足主要结局所需样本，就要说明它影响哪个目标。同一判据可以出现多条发现，复查应沿用各发现的原编号。对不适用项不作负面评价。

### 给作者看的检查结果表

按模块分表。每行只检查一件事，给出可回到原稿的位置，例如“研究方法 §3.2，样本量表第 2 行”。“本稿依据”填本稿的数字、设计或简短原句，并说明判断；不能把下方的通用判据直接复制进报告。评为“需修改”时填一项实际改法并关联批注号。有据可过，在“处理”栏填“保留”即可。同一处证据承担不同判断时，说清每行各查什么。下表为四种写法示例。

| 检查项 | 判断 | 原稿位置 | 本稿依据 | 怎么处理／批注号 |
|---|---|---|---|---|
| 示例 · H04 · 技术路线图 | 通过 | 图 2，随访安排 | 三列分别标明患者、护士及医生的任务，转介条件写在连线上。 | 保留。 |
| 示例 · F05 · 验证组分母 | 需修改 | §3.2 样本量、年度计划表 | 开发组 640 人。按正文的 25% 算，验证应为 160 人；按两家中心各 112 人算，则为 224 人。 | 确认所需验证人数，在两处统一分母。F05-01 |
| 示例 · G08 · 数据权限 | 待核实 | 研究基础 §2，数据合作段 | 文中只说明平台可导出处方，尚未见急诊日期、两端关联码的可用范围。 | 请补合作方准许使用的字段与观察期限。 |
| 示例 · H07 · 预算 | 不适用 | 2026 年青年 C | 当年青年 C 申请实行经费包干制，无单列预算表。 | 跳过预算编报，人员和时限在 D07、H05 核查。 |

## A 标题选择

| 编号与对象 | 在哪里找、怎样核查 | 通过或关闭条件 |
|---|---|---|
| A01 选题复述 | 遮住技术名，复述“谁依据哪种规则分配服务、组织协作、制定或执行政策，哪项管理规律仍不清楚”。对照主要任务，找出最接近这个问题的一项。 | 实际任务能回答所提的管理问题。若主要比较只回答单病种护理疗效，评出方向落差；只见题目时提出区分两者所需的信息。 |
| A02 对象边界 | 分列管理研究对象（制度、规则、组织行为或决策方法）、决策者、观测单位与实证人群。 | 以哪类患者为样本和要对哪项管理机制做推论各自清楚。必要时在副题、摘要交代验证场景；不能仅因样本单一就要求把病种和临床干预放在主标题中心。 |
| A03 核心矛盾 | 删除背景修饰和并列动词，保留一个关键未知；对多目标题查摘要如何将目标串联。 | 能说清为什么多个步骤必须在同一项目内完成，主问题突出，附带任务从属。 |
| A04 概念含义 | 圈出“精准”“动态”“个体化”“学习型”“协同”等实质承诺，到摘要、流程或实例找对应动作。 | 至少能举出一个情境，说明哪个人的哪项信息改变哪一步决定，或什么结果会反馈到下一轮。概念含义清楚即满足，无须堆例。 |
| A05 理论作用 | 题名列理论时，对照研究对象、变量、访谈提纲、机制或干预框架。问若拿掉理论，哪一项设计会变化。 | 能指认一个受理论指导的关键选择；如理论仅提供背景，调整题名权重或展示它实际如何指导设计。 |
| A06 方法必要性 | 题名突出算法、大模型或网络分析时，找出现有做法处理不了的具体困难，与可行的简单方案比较。 | 方法的增益能落到可验证的任务上。即使删去方法名，项目仍有可辨认的问题。 |
| A07 承诺尺度 | 把题名的“预测、效果、机制、构建”等主张与主要比较、组织过程、数据及结局对照。 | 预测有时点与验证，效果有可解释的比较，机制有可区分解释的证据，管理模式有行动主体及运行规则。管理证据缺失时指出任务需改在何处，不能靠改名称或缩窄病种通过。 |
| A08 候选题的取舍 | 有备选题或要求拟题时，比较各题要解释的管理规律，以及现有资料能提供的证据。 | 推荐有正文支撑的研究重点。需要新增决策规则、资源数据或实施观察的题名标明为设计方向，并列出所需改动。 |

<a id="module-b"></a>
## B 背景和意义

| 编号与对象 | 在哪里找、怎样核查 | 通过或关闭条件 |
|---|---|---|
| B01 现实场景 | 在开头标出在哪里、什么人、哪项服务流程发生困难。 | 至少能还原一个与本研究有关的场景。若只有患病率和政策号召，补服务或决策中实际发生的困难。 |
| B02 管理问题 | 从疾病负担继续追到我国服务体系中哪类主体遇到了什么组织、资源或制度约束。核对任务中是否真的比较相应管理规则。 | 能从实践困境提出可检验的管理科学问题。护士实施护理、患者需要帮助、设想节约资源均不能单独满足这一项。 |
| B03 例子承担的作用 | 抽查最难懂的概念和用来解释它的事例，注明是前期观察、文献事实还是设想。 | 读完能说清这个例子支持哪一步问题界定或方法选择。概念已清楚可不举例；虚构情境标为示意，不能当作调查发现。 |
| B04 关键数字口径 | 查疾病或服务负担、趋势与差异中承担论证的数字，辨认年份、地区、人群、来源、分母。 | 查得出数字怎么来的，在何种范围成立。若从全国趋势引出单院问题，有当地材料或清楚的推理边界。 |
| B05 现有做法及后果 | 找出现行做法、适用情境、失效环节和实际后果。 | 读者能复述在什么条件下今天的办法不够用；“力量薄弱”“模式不足”已具体到可观察环节。 |
| B06 科学价值 | 将社会意义与拟增加的认识分别写一句。问预期知道的规律、关系、机制或测量方法是什么。 | 至少一项认识贡献能与主要研究结果对应，即使结果不符预期也有解释空间。 |
| B07 使用价值 | 列明主要使用者，追踪何时接到什么结果、能改变什么行动。 | 从结果到实际行动有清楚路径；不同参与方的利益和角色讲得通。远期影响以有条件的展望表述。 |
| B08 问题的引出 | 阅读立项依据末段，暂时遮住题目，检查前文如何从需求缩小到该未知。 | 结尾的具体问题可以由前文推出；补齐从现象直接跳到建模型或开发平台的中间理由。 |

## C 文献回顾

| 编号与对象 | 在哪里找、怎样核查 | 通过或关闭条件 |
|---|---|---|
| C01 最近似工作 | 对照最接近项目的研究或应用，标出相似的是对象、制度情境、方法还是结局。抽查强新颖性主张的检索依据。 | 能指出与最近似工作的实质差别。无充分检索依据时，将“首次”等强断言收窄或标为待核实。 |
| C02 按问题组织 | 为每段写一句“这一组文献回答什么”，例如现有工具测到了什么、已有干预对谁有效。 | 段末有申请人自己的判断，并与下段或拟开展任务衔接。 |
| C03 证据与论断匹配 | 对关键句标注引文所支持的是制度事实、现状、关联、效果还是机制。 | 论断强度与来源及设计相符；政策文件、横断面关联不会单独被用来证明治疗或政策因果效果。 |
| C04 关键引文核验 | 优先核查首创性、主要效应、量表性能及核心数字。定位原始来源、研究对象和对应结果。 | 可识别并核实出处与含义；原文不可取得时记证据边界，不虚构参考文献、样本、页码或 DOI。 |
| C05 共识与分歧 | 摘出相同问题下相符和冲突的证据，并比较可能的人群、测量、制度及设计差异。 | 能区分已形成的共识、尚无结论和作者自己的推测。有证据分歧时说明为何它影响本项目。 |
| C06 情境迁移 | 对国外工具、政策或服务模式，核对支付制度、照护分工、语言、服务入口等关键差异。 | 指出哪部分可以迁移，哪部分需要本地检验，并在后文找到相应检验安排。 |
| C07 缺口落实为设计 | 将主要文献不足与本项目的一项设计并列，例如费用资料遗漏主观体验和时间变化，对应支出记录、患者报告和纵向测量。 | 每个核心缺口能对应一项实际行动；没有承担任务的宏大缺口降为背景。 |
| C08 新增认识 | 与最近似工作比较，写下若项目完成能多回答的一个问题。 | 增量清楚且有相应证据。若重点是本地适配，写明适配难点和需检验的假设。 |

## D 研究内容

| 编号与对象 | 在哪里找、怎样核查 | 通过或关闭条件 |
|---|---|---|
| D01 总目标可检验 | 对照总目标和主要产出，把“探索、提升、优化”转为结题时可判断的对象或证据。 | 说得出完成什么算回答了问题，研究完成与获得预期方向的结果分得清。 |
| D02 子研究四格 | 对每项任务填“回答的问题／所需资料／怎么做／得到什么”。有空格时定位缺在哪段。 | 资料和操作能产生所承诺的结果，评阅人看得见每项任务的终点。 |
| D03 串联关系 | 对依次执行的任务，找前序产物如何决定后续样本、指标、干预成分或分析条件。 | 说明交接的产物和使用规则，例如如何用预测结果筛出下一阶段参与者。 |
| D04 并行关系 | 对双线或多线研究问何时、由谁、按什么依据整合，以及结果矛盾时怎样处理。 | 给出可执行的汇合点和不能合并时的处理办法。合理的独立并行任务可各自解释与总目标的联系。 |
| D05 问题与任务对照 | 将主要任务与关键问题做双向对应，找出“有问题无任务”及“有大任务无问题”。 | 每个主要未知都获得证据支持，每个主要任务对核心目标的贡献明确。 |
| D06 构建产物检验 | 对平台、量表、策略库、干预方案或工具包，定位谁来检验、检验什么属性、依据什么作判断。 | 产物和评价办法对应。只计划可用性评价的项目，可把结论限定于可用性。 |
| D07 体量与能力 | 对照招募速度、随访长度、开发周期、跨机构协调、人员投入和经费安排。 | 关键任务具备合理规模和负责人。青年项目能看清申请人独立完成的关键部分。 |
| D08 依赖失败 | 选取对全项目最重要的一处依赖，推演模型性能差、资料取不到或招募不足时会怎样。 | 说明可保留的任务、可行替代及需重新限定的结论，备选方案仍指向原科学问题。 |

<a id="module-e"></a>
## E 拟解决的关键问题

| 编号与对象 | 在哪里找、怎样核查 | 通过或关闭条件 |
|---|---|---|
| E01 真正的未知 | 去掉“开展调研、开发系统、构建模式”等动作，问哪种制度或服务规则、组织行为或管理方法的适用条件尚不清楚。 | 能把一般管理问题落到该项目可辨别的差异。若只验证某病的症状传播或护理措施疗效，应明确现有证据最多支持哪项临床认识。 |
| E02 主次与凝练 | 对每个问题标出研究主体、要判断的对象和它与总问题的关系。 | 核心问题突出；属于同一问题的多个工作步骤按需要合并，保留有独立认识价值的子问题。 |
| E03 区分解释 | 面对机制主张，列出一项支持材料、一种竞争解释及能区分两者的观察。 | 设计能获得至少一种有鉴别作用的证据；探索性研究可提出选案对比或准备追踪的过程线索。 |
| E04 分析层级 | 检查患者体验、医务人员行为、机构流程和政策结局的层级，从一层推到另一层时定位中间证据。 | 结论有相应层级的材料，或明示跨层联系的检验与推断边界。 |
| E05 预期被挑战的条件 | 对机制、方向性或效果主张，问什么结果会改变原解释。探索性问题看如何记录相反或意外的发现。 | 说明遇到反例、无差异或模型不可靠时，如何调整解释、设计或应用。 |
| E06 回答后的价值 | 比较解决问题前后，认识、分类、决策或实施行动有何变化。 | 即使研究得到阴性或不一致结果，也能说清新增的认识及其界限。 |

<a id="module-f"></a>
## F 研究方法

按子研究依次做共性检查，随后读取[方法专项](method-checks.md)中命中的节。用研究的问题和实际分析决定适用性。描述性、预测性、因果性、解释性与开发性任务可以并存。

| 编号与对象 | 在哪里找、怎样核查 | 通过或关闭条件 |
|---|---|---|
| F01 对象与单位 | 分列招募、观察、干预和分析单位。特别核查同机构多人、同患者多次测量或机构分配而个体观测。 | 设计和分析能处理有关层级或依赖性，结论指向正确单位。 |
| F02 来源与入组 | 定位招募人、场所、筛选步骤和纳排依据。区分可用的旧数据和需要新收的资料。 | 关键人群可识别，取数路径可执行，对拟取得的数据有进入条件或备选。 |
| F03 时间轴 | 重建入组、暴露或实际政策执行、测量、随访和结局的顺序。对照题摘、图、正文、计划。 | 各阶段窗口一致，最后入组者能完成所需随访，解释符合事件先后。 |
| F04 核心测量 | 对主要结局或核心观察记录定义、单位、工具、评价者、时间窗和来源。 | 可由其他研究者按同一规则记录或提取；质性观察说清记录的事件及语境。 |
| F05 样本量与分母 | 追踪计算参数、单位、组间分配、开发与验证比例、失访、重复测量或中心数。必要时复算。 | 计算与设计相符，各组可加总到总数。质性研究改查选案理由及判断信息是否充分的办法。 |
| F06 数据质量 | 选择最影响主要结果的缺失、失访、重复记录、来源关联、编码变化或测量误差，追问如何发现和处理。 | 说明这些问题如何影响判断，并有与风险匹配的处理或敏感性检查。 |
| F07 方法支持结论 | 为每项主要结论标注证据所能达到的层级，例如描述、预测、机制、因果、可用性或推广。 | 数据支持主张或已收窄表述。若只有医院采购支出，患者自付改善须另有患者端证据。 |
| F08 分析可复述 | 用一个输入、关键处理、输出及判断好坏的依据，复述主要分析。 | 评阅人能区分关键方法决定与软件操作。仅有算法名称处补清该步骤要作出的判断。 |
| F09 比较适合任务 | 识别比较对象、时期和可比依据。工具开发时核对与现有流程或简化方案相比能增加何种用途。 | 比较足以回答设定问题；无需对照的设计说明用于判读的依据，避免强加随机试验。 |
| F10 不确定性 | 选择最可能改变核心结论的假设、偏差或模型选择，说明准备如何发现与评估影响。 | 拟作的检查能检验该项风险；不可检验的假设列入结论边界。 |

## G 研究基础与工作条件

| 编号与对象 | 在哪里找、怎样核查 | 通过或关闭条件 |
|---|---|---|
| G01 成果支撑任务 | 为主要任务寻找可复用的数据、量表、指南、平台、预实验或合作渠道，反查正文哪里用到。 | 能指出这项资源消除了具体哪项不确定性。团队能力可由适当的直接或间接证据支撑。 |
| G02 个人贡献 | 抽查核心成果的具体承担者，辨认申请人、团队和合作方的工作部分。 | 申请人的能力与本次责任相称，重要协作有角色和分工；青年项目能看出独立承担的工作。 |
| G03 已有与拟取得 | 对“已授权、已开发、已建库、可直接调用”等措辞，核验范围、阶段和可用证据。 | 既有、试点、待审批、拟建彼此可辨。缺附件或权限细节时待核，不视为虚假。 |
| G04 预实验可判读 | 对关键图、表、界面或预试结果逐一问对象、条件、指标、已有发现和局限。 | 可以看懂图证明的能力或暴露的问题；概念图、演示原型和真实研究结果有清楚身份。 |
| G05 迁移适用性 | 将旧资源与新任务并列比较人群、机构、测量、数据结构或工作流程。 | 哪部分可复用、哪部分需验证或改造有依据，并在研究内容安排了相应工作。 |
| G06 不足引出新题 | 寻找一项前期尚未解决的具体困难，例如问答系统处理某类问题时答偏。 | 新任务针对已发现的瓶颈，读者理解为什么已有平台仍需进一步研究；有可靠经验资料即可说明。 |
| G07 项目延续与边界 | 对前后项目分别标出对象、数据、已交付产物、新问题与拟得证据。 | 能解释复用和创新各在哪里，前项目已证实的结论不会再次包装为新任务。 |
| G08 条件与缺口 | 把数据授权、团队人员、实施中心、设备和服务渠道对应到最关键任务。 | 已具备的条件有支撑，尚缺条件有取得路径、预计时点和备选方案。 |

## H 其他部分与提交核对

| 编号与对象 | 在哪里找、怎样核查 | 通过或关闭条件 |
|---|---|---|
| H01 摘要自足 | 独立读摘要，复述问题、对象、思路、准备用何证据和预期贡献。 | 摘要与正文一致，明确区分已完成工作和拟开展工作。 |
| H02 关键词 | 逐个回查正文，判断是否帮助识别对象、问题领域或核心方法。 | 关键词贴合项目，名称统一；没有研究任务承接的热门标签可删除。 |
| H03 创新比较 | 为每项创新定位既有做法、改变之处和检验方法。 | 每个重要创新点能与最近似研究作实质比较，验证路径清楚，表达强度与证据相称。 |
| H04 图的作用 | 抽查最复杂的阶段关系、时间点或决策步骤；技术路线图对照输入、处理、输出和去向。 | 图能降低理解成本并与正文一致。纯文字已清楚时可通过；需要补图时说清哪一关系用图更容易核实。 |
| H05 年度进度 | 将招募、随访、开发、分析和验证排到时间轴，检查关键人员和合作条件到位时点。 | 后续任务的启动不早于所需前序结果，最后入组者有完整观察窗。 |
| H06 预期成果 | 反查模型、策略、工具、政策建议、理论贡献与对应研究任务和使用者。 | 成果有适度的判断或验收办法，论文篇数以外能辨认实际产物及其用途。 |
| H07 预算 | 仅在目标年度和项目类别要求预算时，用任务人数、中心数、次数、单价和合作分工核查费用及测算。 | 预算与实际工作量一致，合计可复算；不适用时标明类别、年度及依据。 |
| H08 伦理和权限 | 对访谈、敏感记录、跨机构联通、智能建议等检查相关知情、授权、隐私、复核以及责任人。 | 安排与实际任务相适配，已取得和拟取得文件的状态清楚，所需材料未提供时注明。 |
| H09 年度与类别 | 核对正式模板版本、附件、预算、伦理、AI 使用的核实与声明要求及其他说明。年份变化时查当年官方文件。 | 引用适用于本项目的年度依据；缺当年材料时注明规则待核。2026 面上、青年 C 的正文三部分可与辅导模块分别映射。[改版说明](https://www.nsfc.gov.cn/p1/3381/2821/99242.html) · [2026 年通告](https://www.nsfc.gov.cn/p1/3381/2824/99667.html) |
| H10 全文一致 | 集中比对题摘、方法、图表、预算和计划中的人群、机构数、日期、人数、工具版本、结局、图号及阶段名称。 | 发现差异时能给出两处位置，厘清是否为不同口径，确有矛盾时各相关位置已同步修正。 |

<a id="cross-checks"></a>
## X 全稿复核

| 编号与对象 | 操作 | 完成或关闭条件 |
|---|---|---|
| X01 标题到证据 | 从题名和摘要的核心管理主张逆查决策主体、可比较的规则、实际执行与结局，分别定位到方法、数据和预期产物。 | 能看出哪项证据区分管理机制与临床护理疗效。若管理效果仅有远期展望，写明当前可得结论和还需怎样改设计。 |
| X02 基础到任务 | 抽查最重要的三项前期基础，少于三项时查全部。定位新研究具体在哪一步复用。 | 能说出此次如何使用、降低哪项风险、余下什么未知；分清基础薄弱与尚无机会展示。 |
| X03 图例到主张 | 对最关键的一图一例核对概念、方案、既有数据、原型、个案或设想的身份，回查正文如何解释。 | 图例有特定用途，论断与身份匹配。没有图或案例时检查文字能否承担同一任务，不能凭数量判严重度。 |
| X04 反向复述 | 遮住标题，用管理者、一线专业人员或服务对象的日常语言，复述需要改变的决策，以及该改变会留下什么可观察的差异。 | 能说明研究为哪类管理问题增加认识及其适用条件。若只能说出症状改善，回到 A、B、E 核实管理层解释，不能据“智慧医疗”等术语判通过。 |
