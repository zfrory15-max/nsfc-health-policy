# 年度与项目类型

先取目标年度、项目类型和申请人从信息系统下载的当年模板。请以当年官方指南、项目管理办法、系统内适用表格或正式补充通知核实具体要求。记录适用年度、类别、条文出处及核对日期。用户给定示例中的经验性段式、篇数、分数线均不能作为官方要求。个别条件尚未查实，可继续审读科学问题和研究设计，把相关形式项记为待核实。

## 2026 年 G04 的选题边界

**官方依据。** 管理科学三处要求 G04 从我国实际管理问题中提炼核心科学问题，面向国家重大需求，重视管理理论和方法上的贡献，并明确区分管理科学研究与日常管理工作。指南对**公共卫生管理与政策（G0405）**特别说明，某类疾病的病理、临床与护理研究不在该领域的资助范围内。该条的领域名称不可改写为“全部 G04”。**医药管理与政策（G0406）**应按当年代码、该学科资助说明和原稿实际研究任务判断；用药记录或患病人群本身不足以说明医药管理贡献。[年度指南 · 管理科学三处](https://www.nsfc.gov.cn/p1/2931/3971/3975/3990/4039/glkxsc222.html) · [该页原图（见 G04 末段）](https://www.nsfc.gov.cn/u/cms/www/202601/16142359vvs1.jpg) · [当年申请代码](https://www.nsfc.gov.cn/p1/2931/3971/4002/99887.html)

**实际审读。** 下列是把官方范围用到稿件上的判断办法，例子不作额外形式条件。

| 读到的研究设计 | 评阅时怎么处理 |
|---|---|
| 比较某病的护理干预，主要分析症状、生理变化或临床疗效 | 回看主要对比究竟改变了治疗/护理内容还是服务组织规则。若按 G0405 申报，正文始终围绕疾病临床与护理效果，直接指出与资助范围的冲突。若申请人已确定管理方向，需重构科学问题、对比和数据；仅改题名不能化解。 |
| 从医院、社区、医保部门或药事管理机构的真实决策出发，在一类患者中验证 | 找规则或组织安排、受到影响的行动者、可辨别不同解释的材料及可检验的管理后果。例如在相同随访人力与服务内容下，不同优先分配规则会如何改变高需求患者的及时服务和遗漏？观察实际接触、等待与使用情况，患者症状也可作为最终结局。单病种样本或护士参与并不单独决定适配性。 |
| 申报 G0406，提出药品供应、支付、使用或用药服务组织问题 | 核对具体规则怎样影响机构、专业人员或患者的行为，比较设计和数据能否测到这一环节。例如仅有采购数量不能直接判断患者可负担性。无药事问题的稿件不硬添用药内容。 |
| 稿件只说“提高资源配置效率”，或只提供题目、未标明年度或具体代码 | 指出能改变判断的材料，例如资源约束如何进入分配、原有规则如何比较、后果从何记录。已有正文未支撑的管理主张标需修改；属于未提供的信息标待核实。写明是学科适配风险或有条件的建议，不代替正式受理判断，也不推测官方专家构成。 |

## 已核对的 2026 基线

| 项目 | 对辅导和自评的影响 |
|---|---|
| 范围与代码 | 当年代码表中 G0405 为公共卫生管理与政策，G0406 为医药管理与政策。历史样本按申报时的代码和名称记载。 |
| 正文模板 | 面上和青年 C 的正文围绕立项依据、研究内容、研究基础组织，正文原则上不超过 30 页。A–H 是辅导模块；核对正文时不要求申请人逐项设置八个标题。 |
| 项目体量 | 两类均关注科学价值、创新性、社会影响及方案可行性。面上考察研究团队和工作条件。青年 C 特别注意申请人独立主持和创新研究的能力，个人实际贡献应能与团队平台区分。 |
| 经费 | 面上按预算制，按任务、数量、单价和测算依据核对。青年 C 实行包干制，申请阶段无需编制预算；经费可行性仍可在研究体量中讨论。 |
| 生成式 AI | 申请人对生成内容负责，须人工核实 AI 辅助整理的信息、文献，按要求如实声明使用情况并标识。不得使用 AI 直接生成的申请书或未经核实的生成内容。以提问、提纲、批注与局部示例支持申请人写作。 |

## 跨年度使用

上表只标定 2026。对于 2027 及以后年度，按目标年度重新核对模板、项目名称、预算制式、附件、诚信声明和评议表。区分“征订／预计出版”与“正式发布并适用”。若申报人尚不清楚年度，仍可做方法和论证评价，涉及年度的结论标记待核实。[2027 指南征订通知](https://www.nsfc.gov.cn/p1/3381/2824/142831.html)
