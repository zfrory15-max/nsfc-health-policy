# 国自然 G0405／G0406 标书打磨与模拟函评

`nsfc-health-policy` 是一个中文 Codex Skill，面向已确定申报 **G0405 公共卫生管理与政策**或 **G0406 医药管理与政策**的面上项目、青年科学基金项目（C 类）和地区项目的申请人。只有几个备选标题时，可以先比较选题；已有整稿时，可以请五位匿名模拟专家读完申请书，拿到带原生批注的 Word 和一份逐项核对的模拟函评报告。

## 为什么专门为管理口做一份评阅清单

同样是做出院随访，题目可以很大，管理问题却可能只藏在一个决定里：两位患者同时上报不适，值班护士先回谁？两种分派规则在同样的工时下，会不会漏掉不同的人？Skill 会沿着这类决定读下去，看申请书有没有相应的比较、过程记录和结果指标。遇到医保或药品政策研究，则会追问采购单价、患者自付和实际可及性分别用什么资料衡量。学科范围按申报年度核对。[年度学科依据](references/annual-rules.md)

评阅规则以实际案例反复打磨。案例训练着眼于一个判断标准：一个朴素的例子能否讲清选题，一张图能否说明前后任务怎样衔接，一项前期工作究竟解决了新项目的哪道难题。大量中标案例被用于校准模拟专家评分的松紧。[案例卡](references/case-cards.md) · [资助评价尺度](references/review-workflow.md)

## 九个维度，从选题追到研究细节

整稿评阅填写 **70 项基础检查**，其中八个写作模块共 66 项，跨章节复核 4 项。每一行记录原稿位置、判断依据、修改动作及关联批注号。结果分为“通过、需修改、待核实、不适用”。[完整专业检查清单](references/review-checklist.md)

| 维度 | 检查项 | 典型问题 |
|---|---:|---|
| 标题与选题 | 8 | 去掉理论和技术名，能否一句话说清要解释哪项管理决定？ |
| 背景和意义 | 8 | 谁在什么场景遇到困难，知道答案后会改变哪项行动？ |
| 文献回顾 | 8 | 最接近的研究已经回答了什么？留下的缺口怎样改变本项目的设计？ |
| 研究内容 | 8 | 前一阶段的发现会具体改变下一阶段的选人、干预或比较吗？ |
| 关键科学问题 | 6 | 哪种结果会让申请人修正原来的解释？ |
| 研究方法 | 10 | 入组、比较、随访和结局能对上吗？样本量能否复算？ |
| 研究基础与工作条件 | 8 | 申请人亲自做过什么？哪项成果能支撑本次最难的一步？ |
| 其他部分与提交核对 | 10 | 摘要、创新点、路线图、年度计划中的数字和承诺是否一致？ |
| 跨章节复核 | 4 | 从标题向后追，能否找到兑现核心承诺的任务、数据和判断标准？ |

再按实际设计加查 **8 类方法专项**：预测与风险分层、政策与准实验评价、干预试验、质性与实施研究、混合方法、症状网络、量表与患者报告结局、大模型与数字平台。一份以访谈解释转介中断的标书，会重点查是否访到了中断者、事件顺序能否重建、不同来源是否相互印证。[方法专项清单](references/method-checks.md)

## 整稿评完会拿到什么

1. **带修改批注的申请书副本。** Word 来稿保留原文与排版，批注挂在具体句子、数字或表格上。例如，“每组需要 60 人完成评价，若预计流失 20%，需招募 75 人。请确认正文所列 72 人采用的分母，并同步修改招募计划。”仅提供 PDF 时，交付标明原 PDF 页码的 Word 摘录批注本。
2. **独立的模拟函评报告。** 五位匿名模拟专家各给出综合评价（优、良、中、差）和资助意见（A 优先资助、B 可资助、C 不予资助），分别回答需求背后的基础科学问题、创新性与科学价值、申请人潜力与方案可行性、其他建议四问。首页列总体判断和五份意见，后附逐项检查表。专家可以同档，也可以对同一处设计持不同看法，理由要能回到原稿。

两份 Word 的新增内容统一用宋体。二轮复查沿用原问题编号，可以直接核对上一轮指出的问题是否已经解决。[Word 交付说明](references/word-output.md)

## 安装与使用

1. 在 GitHub 的 **Code → Download ZIP** 下载并解压仓库，把包含 `SKILL.md` 的文件夹命名为 `nsfc-health-policy`。
2. 将整个文件夹放入你的 Codex 项目，确认入口位于 `.agents/skills/nsfc-health-policy/SKILL.md`。如需手动准备 Word 导出环境，可运行 `python -m pip install "python-docx>=1.2,<2" lxml pypdfium2 Pillow`。
3. 在该项目中打开 Codex，附上自己的申请书或已获授权的辅导稿，调用 `$nsfc-health-policy`。有申报年度、项目类型和代码时请一并注明；只有标题或某一节也可以开始。

**选题阶段**

> $nsfc-health-policy 我报 G0405 青年项目。附件有三个备选标题和摘要。请比较每个标题承诺回答什么、我现有的资料能支持到哪里，给出推荐顺序。

**整稿送审前**

> $nsfc-health-policy 我报 G0406 面上项目。请对附件 Word 做五位专家模拟函评，给我原生批注版、独立函评报告和逐项检查表。

**二轮改稿**

> $nsfc-health-policy 附件是修订稿和上轮意见。请按原编号复查，指出哪些修改已经解决问题，哪些改动还需要同步到摘要、路线图或研究计划。
